# Create a Font Awesome icon

Create a Font Awesome icon

## Usage

``` r
faIcon(
  name,
  ...,
  type = c("solid", "regular"),
  class = NULL,
  color = NULL,
  rep = 1,
  style = NULL
)
```

## Arguments

- name:

  Font Awesome icon name.

- ...:

  Reserved for future use.

- type:

  Icon style, either solid or regular.

- class:

  Optional CSS class.

- color:

  Optional CSS color.

- rep:

  Number of icon repetitions.

- style:

  Optional inline CSS.

## Value

An HTML icon tag, or a span containing repeated icons.
