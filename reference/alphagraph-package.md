# Graphical Multiple Comparison Tool

A Shiny interface for designing and analyzing graphical multiple
comparison procedures using the graphicalMCP engine.

## Details

The namespace retains the historical export pattern for compatibility.
Imports are declared with Roxygen tags alongside their implementation.
