# Check an installed package against a maximum version

Check an installed package against a maximum version

## Usage

``` r
isMaximumPackageVersion(maxVersion, pkg, ..., inclusive = TRUE)
```

## Arguments

- maxVersion:

  Maximum package version, as a character string.

- pkg:

  Package name.

- ...:

  Reserved for future use.

- inclusive:

  Whether the maximum version itself is accepted.

## Value

Logical scalar indicating whether the installed version is accepted.
