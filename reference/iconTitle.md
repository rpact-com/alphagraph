# Create a title with an optional icon

Create a title with an optional icon

## Usage

``` r
iconTitle(title, iconName = NULL, iconPosition = c("left", "right"))
```

## Arguments

- title:

  Title text.

- iconName:

  Optional Font Awesome icon name.

- iconPosition:

  Position of the icon relative to the title.

## Value

An HTML span containing the title and optional icon.
